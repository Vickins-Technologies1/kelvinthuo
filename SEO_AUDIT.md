# SEO and personal-brand implementation audit

Date: 2026-10-10  
Site: https://kelvinthuo.vickinstechnologies.com/  
Scope: the existing single-route Next.js portfolio in `app/`

## Findings and implemented fixes

- The site is a single public portfolio route; no project-detail, dashboard, authentication, API, test, or private routes are present in this repository. The sitemap therefore contains only the canonical homepage.
- The existing title and description emphasized senior leadership but did not consistently target Kelvin Thuo's software engineering, IT-specialist, and Kenya positioning. They now use unique homepage metadata centered on Kelvin Thuo and Vickins Technologies.
- Open Graph and Twitter metadata lacked a site name, locale, explicit image dimensions, and a Twitter image. These are now generated from the native Next.js metadata API using the existing 1080 × 1080 portrait.
- There was no structured data. The root layout now emits one JSON-LD array containing a `Person` entity for Kelvin Thuo, an associated `Organization` entity for Vickins Technologies, and a `WebSite` entity for the portfolio. The relationship is represented as affiliation/founder, not as an unsupported employment claim.
- The page had a preloader heading that could be interpreted as a second H1. It is now presentational text, while the hero H1 explicitly identifies Kelvin Thuo as a software builder and technology leader.
- Header and footer landmarks now sit outside the main content landmark. A keyboard skip link, explicit viewport, button types, tab/panel relationships, meaningful project link labels, and image sizing hints were added without changing the visual layout system.
- `sitemap.ts` now uses a stable source modification date instead of generating a new date on every request. `robots.ts` allows the public site and references the canonical sitemap without blocking rendering assets.
